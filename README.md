# Практична робота 1. Основи JAVA

Консольний інтернет-магазин, реалізований за прикладами зі слайдів презентації «Практична робота 1. Основи JAVA». Пакет основної програми відповідає прикладу IntelliJ IDEA: `dut.pd3.practics.practic_1`.

## Склад класів

- `Product` — товар з ID, назвою, ціною (`double`), описом і категорією.
- `Category` — категорія товару з ID та назвою.
- `Cart` — список товарів, додавання та видалення, сума і відображення вмісту, копія списку товарів та очищення кошика.
- `Order` — копія товарів із кошика, загальна сума і початковий статус `Нове`.
- `Main` — категорії й три товари зі слайдів, базове меню та контрольні завдання зі слайду 23.
- `lesson_1.HelloWorld` — перший приклад програми зі слайду 4.

Конструктори, гетери та сетери моделей створюються Lombok. Методи `toString()` перевизначені у форматі, наведеному в презентації.

## Запуск

Потрібні JDK 17+ та Maven 3.9+. У Windows запусти `run.bat` для коректного відображення кирилиці, або виконай у PowerShell:

```powershell
chcp 65001
mvn clean compile
mvn exec:java
```

Щоб запустити окремий приклад `HelloWorld`:

```powershell
java -cp target/classes lesson_1.HelloWorld
```

## Меню магазину

```text
1 - Переглянути список товарів
2 - Додати товар до кошика
3 - Переглянути кошик
4 - Зробити замовлення
5 - Видалити товар з кошика
6 - Переглянути історію замовлень
7 - Знайти товар за назвою або категорією
0 - Вийти
```

Історія замовлень зберігається в пам'яті до завершення програми.

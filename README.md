# Інтернет-магазин на Java

Консольна програма для перегляду каталогу, пошуку товарів, керування кошиком, оформлення замовлень та перегляду історії покупок. Дані зберігаються в пам'яті й доступні протягом поточного запуску програми.

## Вимоги

- JDK 17 або новіший
- Apache Maven 3.9 або новіший

Lombok підключено як `provided` dependency та налаштовано як annotation processor у `pom.xml`.

## Запуск

```powershell
mvn clean compile
mvn exec:java
```

На Windows також можна запустити зібраний застосунок командою:

```powershell
java -cp target/classes ua.edu.shop.Main
```

## Можливості

- Перегляд каталогу та категорій.
- Пошук за назвою товару або назвою категорії.
- Додавання і видалення товарів у кошику.
- Розрахунок суми кошика з `BigDecimal`.
- Оформлення замовлення, очищення кошика та збереження історії замовлень на час роботи програми.
- Перевірка помилкового введення в меню.

## Структура

- `model` — `Product`, `Category`, `Cart`, `Order`.
- `service` — каталог, пошук і оформлення покупок у `ShopService`.
- `Main` — консольне меню та взаємодія з користувачем.
